# FolioCraft – Portfolio Builder

FolioCraft is a simple web-based portfolio builder that helps users create a professional portfolio easily.

## Features

* Add personal details
* Add skills
* Add projects
* Add GitHub and LinkedIn profiles
* Select portfolio themes
* Preview the portfolio
* Simple and responsive design

## Technologies Used

* HTML
* CSS
* JavaScript
